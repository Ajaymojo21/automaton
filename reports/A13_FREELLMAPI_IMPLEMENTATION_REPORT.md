## 4. Design decisions taken (and one the operator may want to reverse)

1. **Every default provider is restated in full.** `fromConfig` *replaces* `DEFAULT_PROVIDERS` as
   soon as the file yields one valid entry (`:283-286`); a file naming only FreeLLMAPI would have
   silently deleted OpenAI, Groq, Together and `local` from failover. The test
   `restates every default provider…` locks the five-id set and `preserves the pre-A13 enable/disable
   posture` locks `together`/`local` at `enabled: false` and all four base URLs verbatim.
2. **`tierDefaults` prefer `freellmapi` for reasoning, fast and cheap.** The prior preferred
   providers (`openai`, `groq`, `groq`) were moved into `fallbackOrder` unchanged. This is the one
   decision that changes *which* provider the agent would use first, and it was taken because the
   cloud providers have no credential anywhere in the tree (`conwayApiKey`/`openaiApiKey` lengths are
   0 and the env vars are unset), so FreeLLMAPI is the only path that can authenticate at all on this
   host. Reverting is a four-line edit in one file.
3. **Model id `auto`, not a pinned upstream model.** Free tier catalogues churn; `auto` is the
   gateway's own stable alias. Cost is declared `0` so the budget tracker
   (`src/inference/budget.ts`) is not fed invented spend. `contextWindow: 131072` /
   `maxOutputTokens: 8192` (4096 for `cheap`) are **declared ceilings, not guarantees** — the real
   ceiling depends on which upstream the router picks.
4. **`supportsTools` is declared `true` for `reasoning`/`fast` and `false` for `cheap`.** FreeLLMAPI
   advertises no per-model tool flag for `auto` (`server/src/routes/proxy.ts:473-488` emits only
   availability and context), and nothing in Conway's registry path gates on `supportsTools` today —
   it surfaces in the model listing (`src/agent/tools.ts:2118`) and the pickers. Flagged as a known
   uncertainty rather than a verified property.
5. **The credential lives in the process environment only** — `apiKeyEnvVar: "FREELLMAPI_API_KEY"`,
   read at call time by `resolveApiKey` (`:446-450`). No key is stored in the tree, and the test
   `keeps secrets out of the template file itself` rejects `sk-…`, `Bearer …` and any `"apiKey":`
   value in the file. With the variable unset the registry sends the documented placeholder
   `missing-freellmapi_api_key` (`:446-457`) and FreeLLMAPI answers **401** — a loud failure, not a
   silent unauthenticated call.
